# OSRS icons

`metrics/`, `player_types/`, and `group_roles/` are copied from the
[Wise Old Man](https://github.com/wise-old-man/wise-old-man) web app
(`app/public/img`, MIT licensed). Filenames match the slugs the WOM API returns,
so a metric / account-type / group-role string maps straight to an icon
(see `src/components/wom/Icon.tsx`). The underlying artwork is Old School
RuneScape content © Jagex.
